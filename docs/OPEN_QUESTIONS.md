# 애매한 부분 (결정 필요)

초안에서는 아래 항목을 **임시값으로만** 넣어두었어요. 확정되면 해당 파일을 고치면 됩니다.

## 수치와 규칙
1. **관계 수치 범위와 변화폭**: 지금은 -100~100, 한 번에 ±10까지. 호감·신뢰·애정의 차이(예: 애정은 호감이 일정 이상일 때만 오르는지)는 정하지 않았어요. (`js/state.js`, `js/ai.js`)
2. **NPC 기억 개수**: NPC마다 최근 20개만 저장하고, AI에게는 최근 5개만 보내요. (`js/state.js`, `js/ai.js`)
3. **능력치의 실제 효과**: 능력치가 AI 판정에 참고만 될 뿐, 성공/실패 확률 같은 규칙은 없어요.
4. **프리셋 숫자 전체**: 능력치 종류와 값, 초기 돈, 초기 관계, 시간 범위, 목표 기간(모두 30일)은 임시값이에요. (`js/presets.js`)
5. **엔딩 조건**: 진행도 100이면 좋은 결말, 기한이 지나면 진행도 50 이상은 평범, 미만은 나쁜 결말이에요. 세계관별 고유 엔딩 조건이나 AI가 엔딩을 정하는 방식은 정하지 않았어요.
6. **목표 진행도를 누가 올리나**: 지금은 AI가 행동마다 0~10을 줘요. 명확한 조건(예: 특정 플래그 달성)으로 할지 정해야 해요.
7. **시간대 구분**: 아침 6~12시, 낮 12~18시, 저녁 18~22시, 밤 22~6시. 세계관마다 다르게 할지?
8. **"다음 날 아침까지" 버튼**: 세계관 시작 시각(예: 8시)까지 건너뛰어요. 수면으로 체력이 회복되는 규칙은 없어요.

## 성인 모드
9. **성인 확인 방법**: 지금은 "만 19세 이상입니까?" 확인 창 하나예요. 기준 나이와 방식을 정해야 해요.
10. **미성년자 보호를 어떻게 강제할지**: 지금은 (1) AI 프롬프트의 절대 규칙과 (2) 세계관 저장 시 18세 미만 NPC 거부, 두 가지뿐이에요. 한국 기준 19세로 맞출지, 추가 검사가 필요한지 정해야 해요.
11. **일반 모드의 Gemini 안전 필터 단계**: `BLOCK_MEDIUM_AND_ABOVE`로 두었어요.

## AI
12. **기본 모델과 목록**: `gemini-2.5-flash`를 기본으로, 목록에 2.5 계열 3개를 넣었어요. 지금 쓰시는 최신 모델명을 알려주시면 바꿀게요.
13. **대화 기록 전달량**: AI에게 최근 12개 메시지만 보내요. 오래 플레이하면 앞 내용을 잊을 수 있어서, 요약 기능이 필요할지 정해야 해요.
14. **하루 소식 개수와 영향 범위**: 1~3개, 세력과 플래그만 바꿀 수 있어요. NPC끼리의 관계 수치는 아직 저장하지 않아요(소식 문장으로만 표현).

## 화면과 기능
15. **세계관 에디터 형태**: 지금은 JSON 텍스트를 직접 고치는 방식이에요. 입력 폼 에디터가 필요한지 정해야 해요.
16. **세이브 슬롯 개수**: 5개.
17. **테스트 모드 반응 수준**: 지금은 아주 단순한 고정 문장이에요. 프리셋별로 짜둔 시나리오를 얼마나 넣을지 정해야 해요.
18. **GitHub Pages 배포**: 코드는 준비됐지만, 저장소 설정에서 Pages를 켜는 건 직접 하셔야 해요. 어느 브랜치에서 배포할지(보통 `main`) 정해야 해요.
