# 결정 기록

## 확정된 결정
| 항목 | 결정 |
|---|---|
| 관계 수치 | -100~100. 사람처럼 판단(평범 0~2, 인상적 3~8, 중요 10~20). 결정적 사건만 최대 ±50 |
| NPC 기억 | 원본은 개수 제한 없이 전부 저장·표시. AI에는 오래된 기억을 요약해서 보냄 |
| 능력치 | 이야기와 대화의 결과·디테일에 반영. 시작 값은 API 키가 있으면 AI가 성격을 보고 정함(종류는 세계관 것 유지) |
| 엔딩 | 기간이 아니라 이야기 상황으로 AI가 판단. 기한이 중요한지도 AI가 세계관을 보고 판단 |
| 목표 진행도 | 행동의 기여도에 따라 AI가 정함 |
| 시간대 | 새벽 0~6 / 아침 6~9 / 오전 9~12 / 점심 12~13 / 오후 13~18 / 저녁 18~21 / 밤 21~24. NPC 일과도 7구간 |
| 수면·휴식 | 버튼과 직접 입력 모두 회복. 6시간 이상이면 완전 회복, 짧으면 비례해서 적게 |
| NPC끼리 관계 | 방향별 호감·신뢰·애정. 프리셋은 첫 관계를 정해둠. 하루 소식과 행동으로 변함 |
| 성인 확인 | 만 19세 확인 창 |
| 미성년자 보호 | AI 프롬프트 절대 규칙 + 18세 미만 NPC 세계관 저장 거부 |
| 안전 필터 | 항상 최하 단계(BLOCK_NONE) |
| 모델 | 자동: 이야기 진행은 상위 모델부터, 요약은 가벼운 모델부터. 한도 초과·과부하 시 다음 모델로 전환 |
| 요약 | 대화 30개가 쌓이면 최근 12개만 남기고 줄거리 요약에 합침. 원본 기록은 유지 |
| 세계관 에디터 | JSON 방식 유지(폼은 필요할 때 요청) |
| 세이브 슬롯 | 5개 |

## 2026-10 추가: 외부 서비스 참고 (플레이 로그 + UI 자료)
참고 자료는 구조와 규칙을 뽑는 데만 썼고, 인물·지명·문장은 새로 만들었다.

| 항목 | 내용 |
|---|---|
| 응답 렌더러 (`js/render.js`) | AI 응답의 `> 헤더`, `*지문*`, `**이름**: "대사"`, 💭 속마음, 코드블록 상태창을 나눠 보여준다. `{{asset:…}}` 이미지 코드는 지운다. HTML은 요소로 만들지 않고 글자로만 보인다. |
| 화면 표시 설정 | 채팅형(문단마다 말풍선) / 소설형(지문은 배경 위에, 대사만 말풍선), 글자 크기·줄 간격 5단계. 상단 `Aa` 버튼, `rp.display`에 저장 |
| 생존 수치 `meters` | 포만감·수분 같은 수치를 시간이 지나면 앱이 줄인다(자는 동안은 느리게, `restRecoverPerHour`로 회복). AI는 행동 결과만 `meterChanges`로 알린다 |
| `opening`, `initialFlags` | 프리셋이 정해 둔 첫 장면(`{이름}`은 주인공 이름으로 치환)과 시작 플래그 |
| 새 프리셋 | 무인도 표류: 해무의 섬 (생존 수치, 거처 4단계, 관계 5단계), 봉쇄 도시: 청암시 (구역 점령, 판정 줄, 임무 카드 먼저) |
| 의도적으로 가져오지 않은 것 | 성적 강요·폭력 장면, 어린 이미지 표현. 모든 인물은 나이가 명시된 성인(20세 이상), 합의 없는 성적 행위는 묘사하지 않는다는 규칙을 프리셋에 넣었다 |
| 호감도 단계 방식 | 원본은 "단계 안에서 0~100%가 차면 다음 단계로" 이지만, 이 앱은 하나의 호감도 값에 `relationStages` 경계를 둔다 |
