# 시뮬레이션 RP 게임 설계서 (1페이지)

**한 줄 요약**: 뼈대(장소·캐릭터·세력·목표)가 정해진 세계관 안에서, 플레이어가 자유롭게 행동하면 Gemini AI 게임 마스터가 반응을 만들어 주는 웹 브라우저 시뮬레이션 RP 게임.

- **플랫폼**: 웹 브라우저 (PC와 모바일), 공개 저장소 + GitHub Pages 배포
- **AI**: 플레이어가 입력한 Gemini API 키 사용 (키는 브라우저에만 저장)
- **언어/화면**: 한국어, 채팅/로그형 + 상태 패널, 텍스트와 아이콘 중심

---

## ✅ 꼭 들어가야 하는 것 (필수)

| 영역 | 내용 |
|---|---|
| **세계관** | 데이터로 정의된 뼈대(장소, NPC, 세력, 메인 목표, 사용 모듈, 시간 기준) 위에서 AI가 상호작용 생성 |
| **프리셋 6종** | 🏰 판타지 왕국 · 🎓 현대 대학 캠퍼스 · 🚀 SF 우주 정거장 · 🏯 조선 궁중 사극 · 🧟 아포칼립스 생존 · 🍵 힐링 카페 경영 |
| **세계관 제작** | 한 줄 설명으로 AI 초안 생성 → 에디터에서 수정, 프리셋 복사 후 수정 |
| **플레이어 캐릭터** | 세계관별 기본 주인공(역할, 배경, 초기 능력치/관계) + 이름·성격·외모 직접 설정 |
| **관계 시스템** | NPC별 호감·신뢰·애정 수치와 플레이어에 대한 기억 기록 |
| **시간 흐름** | 날짜와 시각. AI가 행동마다 걸린 시간을 판단하되, 세계관별 기본 간격(보통 1시간)과 최소/최대 범위 안에서만 조절. "시간 넘기기" 버튼 |
| **NPC** | 시간대별 일과(장소 이동). 하루가 끝나면 AI가 NPC 간 관계 변화·사건을 한 번에 생성해 소식으로 전달 |
| **세계 상태** | 세력 관계, 사건, 플래그가 플레이어 행동에 따라 변화 |
| **선택 모듈** | 경제/자원(돈·인벤토리), 가벼운 능력치(3~5개). 세계관마다 켜고 끔 |
| **목표/엔딩** | 세계관별 메인 목표(날짜 제한 없음)와 여러 엔딩, 엔딩 후 계속 플레이, AI 서브 퀘스트 |
| **입력 방식** | AI 선택지 3~4개 + 자유 입력, 지도 이동·캐릭터 목록·인벤토리·시간 넘기기 버튼 |
| **AI 연결** | Gemini 기본, 설정에서 API 키·모델 선택. 연결 코드는 분리해 다른 AI 추가 가능. 응답 길이 기본 "보통"(설정 변경 가능) |
| **테스트 모드** | API 키 없이도 미리 짜둔 반응으로 기본 플레이 가능 |
| **저장** | 자동 저장 + 여러 세이브 슬롯 + 파일 내보내기/불러오기. 직접 만든 세계관도 파일로 공유 |
| **성인 모드** | 설정에서 성인 확인 후 켜기. 켜면 성인 콘텐츠 제한을 풀고 Gemini 안전 필터를 최저(`BLOCK_NONE`)로 요청. 응답이 차단되면 "다시 시도" 안내 |
| **절대 규칙** | 미성년자 캐릭터가 나오는 성적 콘텐츠는 어떤 모드에서도 항상 차단 |

## ➖ 빼도 되는 것 (이번 범위 밖)

- 캐릭터·배경 이미지, AI 이미지 생성 (텍스트와 아이콘만 사용)
- 영어 등 다국어 지원
- 자체 서버, 로그인, 계정, 클라우드 저장
- Gemini 외 다른 AI 실제 연결 (구조만 준비)
- 비주얼 노벨풍, 텍스트 어드벤처풍 화면
- 모바일 앱, PC 설치형 버전
- 효과음, 배경음악

## 🏁 완료 기준

1. GitHub Pages 주소로 접속하면 PC와 모바일 브라우저에서 모두 정상 표시되고, 가로 스크롤이 생기지 않는다.
2. 설정에서 Gemini API 키와 모델을 입력하면 AI 게임 마스터가 응답하고, 키는 브라우저 밖으로 전송되지 않는다(Gemini API 호출 제외).
3. API 키 없이 테스트 모드로 6개 프리셋을 시작해 기본 행동(대화, 이동, 시간 넘기기)을 할 수 있다.
4. 기본 주인공의 이름·성격·외모를 바꿔 게임을 시작하면, 바꾼 성격이 AI 묘사에 반영된다.
5. NPC와 상호작용하면 호감·신뢰·애정 수치와 기억이 갱신되고 상태 패널에 보인다.
6. 행동마다 시간이 세계관 범위 안에서 흐르고, NPC가 시간대별로 다른 장소에 있다.
7. 하루가 끝나면 NPC 간 사건 소식이 표시되고, 세계 상태(세력·플래그)가 바뀔 수 있다.
8. 경제·능력치 모듈이 켜진 세계관에서만 돈, 인벤토리, 능력치가 표시되고 작동한다.
9. 메인 목표 진행도가 보이고, 조건을 달성하면 엔딩이 나오며, 엔딩 뒤에도 계속 플레이할 수 있다.
10. 한 줄 설명으로 AI가 새 세계관을 만들고, 에디터에서 수정해 플레이할 수 있다.
11. 자동 저장된 게임을 새로고침 후 이어할 수 있고, 슬롯 저장/불러오기와 세이브·세계관 파일 내보내기/불러오기가 작동한다.
12. 성인 모드는 성인 확인 없이는 켜지지 않고, 미성년자 관련 성적 콘텐츠는 모드와 상관없이 차단된다.
13. 응답 차단·키 오류·네트워크 오류가 나면 게임이 멈추지 않고 이해하기 쉬운 안내가 나온다.
